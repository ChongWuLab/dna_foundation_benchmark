This is the directory meant to store all datasets used for this project. Please download data_processed.zip from https://huggingface.co/datasets/hfeng3/dna_foundation_benchmark_dataset/tree/main, and copy all files into this directory.
The resultant directory structure should be:
```
dna_foundation_benchmark/
│
├── data_processed/
│   ├── enhancers/
│   │   ├── enhancer/
│   │   │   ├──train.csv
│   │   │   ├──test.csv
│   │   ├── enhancer_strength/
│   │   │   ├──train.csv
│   │   │   ├──test.csv
│   │── ...   
├── analysis/
├── job_scripts/
```
